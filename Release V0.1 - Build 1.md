HorizonOS Oneplex V0.1

Development Edition

Finalizada em 14/08/2026

A primeira versão finalizada do projeto HorizonOS Oneplex.

A V0.1 representa a fundação sobre a qual as versões seguintes foram construídas.

🌅 O que havia na V0.1

A versão estabeleceu a estrutura inicial do projeto, incluindo:

- Terminal do HorizonOS
- Engine
- módulos do console
- componentes do Kernel
- BIOS
- componentes de interface
- sistemas de animação
- informações do sistema
- programas experimentais
- recursos relacionados à segurança
- primeiras funcionalidades de comandos

A maior parte do desenvolvimento dessa versão foi focada em experimentar diferentes ideias e descobrir como os componentes poderiam funcionar juntos.

🧪 Uma versão de desenvolvimento

A V0.1 deve ser considerada uma versão experimental.

Diversos componentes eram protótipos ou implementações iniciais que posteriormente foram modificados, reorganizados ou removidos durante o desenvolvimento da V0.2.

Mesmo assim, essa versão representa uma etapa importante na história do HorizonOS.

Ela foi o ponto de partida para a arquitetura que viria depois.

V0.1 estabeleceu as bases.

V0.2 construiria sobre elas.
