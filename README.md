# HorizonOS_Oneplex


HorizonOS Oneplex

Um simulador experimental de sistema operacional desenvolvido em Python.

O HorizonOS Oneplex é a evolução do projeto originalmente chamado HorizonOS Professional XWin One.

O projeto nasceu como uma forma prática de estudar e experimentar conceitos relacionados a sistemas operacionais utilizando Python, criando componentes como terminal, Engine, BIOS, comandos, módulos de sistema, animações e diversos recursos experimentais.

«⚠️ O HorizonOS não é um sistema operacional real e não pretende substituir Windows, Linux ou qualquer outro sistema operacional. Ele é um simulador experimental e um projeto de aprendizado.»

---

🚀 Evolução do projeto

V0.1 • Development Edition

A primeira grande versão do HorizonOS.

A V0.1 estabeleceu as primeiras bases do projeto, incluindo o terminal, Engine, Kernel, BIOS, componentes de interface e diversos programas experimentais.

Foi principalmente uma versão de desenvolvimento, onde várias ideias foram testadas pela primeira vez.

V0.2 • Coffee Edition "beta"

A V0.2 representa uma grande evolução em relação à primeira versão.

O projeto recebeu uma nova arquitetura de comandos, suporte a argumentos, reorganização da Engine, novos módulos, melhorias no terminal, Status Bar, Dynamic Bar, sistemas de animação, ThreadingManager e diversas outras mudanças internas.

Também houve uma grande limpeza e reorganização do projeto, com componentes experimentais da V0.1 sendo removidos, substituídos ou reorganizados.

---

🛠️ Filosofia

O HorizonOS é desenvolvido através de experimentação.

Novas ideias são prototipadas, testadas, modificadas e, quando fazem sentido para o projeto, integradas ao sistema principal.

O objetivo não é simplesmente criar uma grande quantidade de código, mas aprender como diferentes componentes podem trabalhar juntos.

«1 ideia para infinitas possibilidades...»

---

🚧 Futuro

O projeto continua em desenvolvimento.

Entre as ideias que podem aparecer em versões futuras estão:

- melhorias no HotScript
- integração do HotScript com a Engine
- sistema de gerenciamento da Engine
- manipulação de arquivos pela Engine
- configurações baseadas em JSON
- usuários separados
- DevMode
- filesystem simulado
- disquete simulado
- emulador de CPU
- melhorias no sistema de animações
- novos comandos de terminal
- melhorias no sistema de logs e tratamento de erros

Essas ideias fazem parte do desenvolvimento experimental e não representam necessariamente funcionalidades garantidas para a próxima versão.
